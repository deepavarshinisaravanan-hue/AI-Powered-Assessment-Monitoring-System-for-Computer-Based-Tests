# Assessment Monitoring System

This workspace contains the initial project structure for an Assessment Monitoring System with:

- React + Vite frontend in the frontend folder
- FastAPI backend in the backend folder
- PostgreSQL configuration via backend/.env
- Tailwind CSS configured for the Vite frontend

## Structure

- frontend/: React + Vite + Tailwind app
- backend/: FastAPI app, environment config, and package requirements

## Verification

- Frontend build: npm run build
- Backend health endpoint: http://127.0.0.1:8000/
